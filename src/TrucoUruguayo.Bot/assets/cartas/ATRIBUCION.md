# Atribución del dorso de carta (`dorso.png`)

Sale del repositorio [RolandoAndrade/juego-truco](https://github.com/RolandoAndrade/juego-truco)
(`UILayer/src/main/resources/back.png`), un proyecto de cátedra ("Redes de
Computadores I") de Rolando Andrade y José Cedeño.

- **Licencia:** el repositorio no incluye un archivo `LICENSE`. El diseño es un
  dorso de carta clásico estilo Bicycle genérico, no parece arte original de
  los autores del repo — pero no hay una licencia explícita que citar.

Nota: el mazo clásico que también salía de este repositorio se dio de baja
(las 40 imágenes de cartas se borraron); este dorso se mantiene porque el
efecto visual de la mesa lo usa independientemente del mazo activo. Ver
`mazo_basico/ATRIBUCION.md` para la atribución de las cartas del mazo básico.

# Atribución de las imágenes de cartas

Las 40 imágenes de esta carpeta (`{numero}_{palo}.png`) provienen del repositorio
[mcmd/playingcards.io-spanish.playing.cards](https://github.com/mcmd/playingcards.io-spanish.playing.cards),
que a su vez las toma de Wikimedia Commons:
[Baraja española completa](https://commons.wikimedia.org/wiki/File:Baraja_espa%C3%B1ola_completa.png).

  (Creative Commons Atribución-CompartirIgual 3.0).

  por carta y se renombraron a `{numero}_{palo}.png` (ej. `12_oro.png`). No se
  modificó el contenido visual de las cartas.

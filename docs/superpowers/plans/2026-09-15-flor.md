# Sistema de Flor — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agregar Flor al motor de Truco (`Ronda.cs`): detectarla, calcular sus puntos, cantarla (+3 puntos directos) y bloquear envido/jugar-carta hasta que se cante si corresponde; exponerla en `TrucoModule.cs`.

**Architecture:** `Ronda.EsPieza`/`ValorPieza` delegan en el `GestorDeJerarquia` ya existente (`Ronda.Gestor`) en vez de reimplementar la detección de piezas. `TieneFlor`/`CalcularPuntosFlor` son cálculos puros sobre la mano original de 3 cartas (igual que el envido). `CantarFlor` sigue el mismo patrón que `CantarEnvido`/`GritarTruco`: valida y muta estado, tira `InvalidOperationException` si algo no corresponde. Ese mismo patrón se usa para bloquear `CantarEnvido`/`JugarCarta` cuando hay flor sin cantar. `TrucoModule` solo agrega una opción al select menu y un `try/catch` (igual que todos los demás handlers de canto).

**Tech Stack:** C# / .NET 10, xUnit (tests de `Ronda` son unitarios puros, sin base de datos — usan el helper `NuevaRondaConMazoFijo` de `RondaTests.cs`, con `Muestra = new(3, Palo.Oro)` fija, así que las piezas de estos tests son siempre 2/4/5/11/10 de Oro).

## Global Constraints

- `ValorPieza`: 2→30, 4→29, 5→28, 11→27, 10→27 (del palo de la muestra, incluyendo pieza promovida vía `Gestor`); 0 si no es pieza.
- `TieneFlor`: 2-3 piezas → true; 1 pieza → true si las otras 2 comparten palo; 0 piezas → true si las 3 comparten palo; si no, false.
- `CalcularPuntosFlor`: 0 piezas → `20 + Σ ValorEnvido`; 1 pieza → `ValorPieza + Σ ValorEnvido(otras 2)`; 2 piezas → `ValorPieza(alta) + ValorPieza(baja)%10 + ValorEnvido(no-pieza)`; 3 piezas → `ValorPieza(alta) + ValorPieza(media)%10 + ValorPieza(baja)%10`. Verificado contra el ejemplo dado: 2+4+5 de Oro → 47.
- `CantarFlor` suma 3 puntos fijos (flor directa simplificada, sin quiero/no quiero) y no cambia `Estado` ni `TurnoActual`.
- El chequeo "tiene flor sin cantar" bloquea `CantarEnvido` y `JugarCarta`, con mensajes exactos: `"¡Tenés Flor! Debés cantarla antes del envido."` y `"¡Tenés Flor! Debés cantarla antes de jugar una carta."` — va inmediatamente después del chequeo de turno existente en cada método, nunca antes (el error de turno tiene prioridad).
- Toda la validación vive en `Ronda` (tira `InvalidOperationException`); `TrucoModule` solo hace `try/catch` como en el resto de los handlers de canto — no hay `if` sueltos de reglas de juego en `TrucoModule`.

```csharp
    public bool TieneFlor(ulong jugadorId)
    {
        var mano = jugadorId == Jugador1Id ? _manoOriginalJugador1 : _manoOriginalJugador2;
        var piezas = mano.Where(EsPieza).ToList();

        if (piezas.Count >= 2)
        {
            return true;
        }

        if (piezas.Count == 1)
        {
            var restantes = mano.Where(c => !EsPieza(c)).ToList();
            return restantes[0].Palo == restantes[1].Palo;
        }

        return mano[0].Palo == mano[1].Palo && mano[1].Palo == mano[2].Palo;
    }

    public int CalcularPuntosFlor(ulong jugadorId)
    {
        var mano = jugadorId == Jugador1Id ? _manoOriginalJugador1 : _manoOriginalJugador2;
        var piezas = mano.Where(EsPieza).OrderByDescending(ValorPieza).ToList();

        if (piezas.Count == 0)
        {
            return 20 + mano.Sum(Gestor.ValorEnvido);
        }

        if (piezas.Count == 1)
        {
            var restantes = mano.Where(c => !EsPieza(c));
            return ValorPieza(piezas[0]) + restantes.Sum(Gestor.ValorEnvido);
        }

        var total = ValorPieza(piezas[0]);
        for (var i = 1; i < piezas.Count; i++)
        {
            total += ValorPieza(piezas[i]) % 10;
        }

        if (piezas.Count == 2)
        {
            var tercera = mano.First(c => !EsPieza(c));
            total += Gestor.ValorEnvido(tercera);
        }

        return total;
    }
```
